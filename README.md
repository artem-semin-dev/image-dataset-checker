# Image Dataset Checker

Небольшой учебный Python-проект для первичной проверки папки с изображениями перед разметкой датасета или обучением модели компьютерного зрения.

Проект не связан с конкретной компанией и не заменяет ручную проверку разметки. Он автоматизирует повторяемую часть подготовки данных: находит битые файлы, изображения с недостаточным разрешением и точные дубликаты, затем сохраняет результат в CSV.

## Что умеет

- рекурсивно проверять `BMP`, `GIF`, `JPEG`, `PNG`, `TIFF` и `WEBP`;
- определять формат, размер в пикселях и размер файла;
- помечать повреждённые или нераспознаваемые изображения;
- находить точные дубликаты по SHA-256;
- проверять минимальную ширину и высоту;
- создавать CSV-отчёт, который можно открыть в Excel или Google Sheets.

## Быстрый запуск

Нужен Python 3.10+.

```powershell
py -m pip install -e .
image-dataset-checker .\demo_images --min-width 640 --min-height 480 --overwrite
```

Или без установки самого пакета (предварительно установите Pillow):

```powershell
py -m pip install "Pillow>=10.0"
$env:PYTHONPATH = "src"
py -m image_dataset_checker .\demo_images --min-width 640 --min-height 480 --overwrite
```

Демонстрационные файлы уже находятся в `demo_images`. Если этой папки нет, её можно создать командой `py examples/create_demo.py`.

По умолчанию в проверяемой папке создаётся `image_dataset_report.csv`. Для повторного запуска укажите другой путь либо добавьте `--overwrite`, чтобы заменить существующий CSV-отчёт:

```powershell
image-dataset-checker .\images --output .\reports\dataset.csv
```

## Формат отчёта

| Поле | Значение |
| --- | --- |
| `path` | Путь к изображению относительно проверяемой папки |
| `status` | `ok`, `too_small`, `duplicate`, `duplicate_too_small` или `corrupt` |
| `format` | Формат, который определила Pillow |
| `width`, `height` | Размер в пикселях |
| `size_bytes` | Размер файла |
| `sha256` | Хеш содержимого файла |
| `duplicate_of` | Первый файл с таким же содержимым, если это дубликат |
| `details` | Краткое пояснение статуса |

## Проверка тестов

Тесты не требуют сети и создают временные изображения сами:

```powershell
$env:PYTHONPATH = "src"
py -m unittest discover -s tests -v
```

## Ограничения

- Дубликаты определяются по идентичному содержимому файла. Визуально похожие, но по-разному сохранённые изображения не считаются дубликатами.
- Первым считается файл, который идёт раньше по алфавиту относительных путей; последующие копии ссылаются на него.
- Проверяются только файлы с поддерживаемыми расширениями.
- В многокадровых изображениях проверяется первый кадр.
- Инструмент не оценивает качество разметки объектов: он готовит исходные изображения к следующему этапу работы.
